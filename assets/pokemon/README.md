# Pokemon Images

В этой папке хранятся локальные директории под изображения покемонов.

Зачем это нужно:
- здесь удобно раскладывать картинки по папкам до загрузки в MinIO/S3
- структура создаётся автоматически по именам покемонов из `pokedex_all_pokemon_with_safebooru.xlsx`

Как пересоздать папки:

```bash
uv run python scripts/create_pokemon_name_dirs.py
```

После запуска появятся подпапки по именам покемонов внутри `assets/pokemon/`.

Как пользоваться:
- найдите папку нужного покемона
- положите туда изображение этого покемона
- позже эти файлы можно будет массово загрузить в object storage

Важно:
- git не хранит пустые папки, поэтому сами директории покемонов не коммитятся, пока внутри них нет файлов
- если папки исчезли или проект клонировали заново, просто снова запустите скрипт выше
