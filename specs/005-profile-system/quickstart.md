# Quickstart: Profile System

## Open Main Screens

- `/profile` открывает экран профиля
- Кнопка `Профиль` в меню ведёт в тот же раздел
- `/search <имя>` ищет покемона по имени

## Settings Flows

### Nickname

1. Открыть `Профиль -> Настройки -> Смена ника`
2. Отправить следующим сообщением новый ник
3. Бот сохраняет значение и обновляет экран настроек

### Language

1. Открыть `Профиль -> Настройки -> Язык`
2. Выбрать `Русский` или `English`
3. Значение сохраняется в `user_settings.language`

### Cover

1. Открыть `Профиль -> Настройки -> Обложка`
2. Отправить имя покемона
3. Бот ищет только среди покемонов пользователя, у которых есть картинка
4. Если найден один вариант, обложка сохраняется сразу
5. Если найдено несколько вариантов, бот показывает короткий список выбора

## Search Flow

1. Выполнить `/search pikachu`
2. Если найден один результат, бот сразу отправляет карточку
3. Если найдено несколько результатов, бот отправляет компактный список с кнопками
